- **Frontmatter Pyrite cannot model is refused for writes and reported, with the line (#760).** A file whose frontmatter holds a tagged key (`!!str flag: 1`), a complex key (`? [a, b]`) or a duplicate key gets no write through Pyrite, body included: an update is refused with `VALIDATION_FAILED` and the reason, nothing written. Such a file is no longer invisible: `pyrite index health` lists them under `unmodellable_frontmatter` ("N file(s) whose frontmatter Pyrite cannot model", path, line and reason; a warning), and `pyrite qa validate` reports one `frontmatter_unmodellable` issue per file with the same line. Fix the key by hand.
